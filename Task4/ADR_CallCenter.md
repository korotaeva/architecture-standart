# ADR: Передача депозитных ставок в кол-центры (внутренний и партнерский)

## Название задачи:
Обеспечение доступа к актуальным депозитным ставкам для внутреннего и партнерского кол-центров

## Функциональные требования

| № | Действующие лица или системы | Use Case | Описание |
|---|-----------------------------|----------|-----------|
| 1 | Менеджер внутреннего кол-центра | Консультация по текущим ставкам | 1. Получает запрос от клиента<br>2. Проверяет актуальные ставки в CRM-системе<br>3. Консультирует клиента на основе актуальных данных |
| 2 | Менеджер партнерского кол-центра | Консультация по текущим ставкам | 1. Получает запрос от клиента<br>2. Проверяет актуальные ставки в локальной системе<br>3. Консультирует клиента на основе полученных данных |
| 3 | Администратор АБС | Обновление депозитных ставок | 1. Обновляет ставки в АБС<br>2. Инициирует процесс экспорта данных<br>3. Контролирует успешность передачи данных |
| 4 | Система АБС | Автоматический экспорт ставок | 1. По расписанию выгружает актуальные ставки<br>2. Формирует файлы в требуемых форматах<br>3. Обеспечивает передачу через SFTP |
| 5 | Партнерский кол-центр | Импорт данных о ставках | 1. Автоматически забирает файлы через SFTP<br>2. Обновляет локальную базу данных<br>3. Уведомляет операторов об обновлении информации |

## Нефункциональные требования

| № | Требование |
|---|------------|
| 1 | Актуальность данных: максимальная задержка обновления - 1 час |
| 2 | Безопасность: шифрование данных при передаче через SFTP |
| 3 | Надежность: доступность данных 99.9% времени |
| 4 | Совместимость: поддержка форматов CSV и XML |
| 5 | Мониторинг: отслеживание успешности передачи файлов |
| 6 | Резервирование: механизм повторной отправки при сбоях |

## Решение

### Архитектурный подход

Для решения задачи предлагается **гибридная архитектура**:
- **Прямой API-доступ** для внутреннего кол-центра через REST API
- **SFTP-обмен файлами** для партнерского кол-центра
- **Единый источник данных** - АБС банка

### Ключевые компоненты системы

#### 1. Модуль управления ставками в АБС
- **Хранение данных**: Oracle Database
- **Логика управления**: PL/SQL процедуры
- **Экспортный модуль**: Генерация файлов для внешних систем

#### 2. Сервис интеграции
- **SFTP Server**: Обеспечение безопасной передачи файлов
- **API Gateway**: Предоставление данных внутренним системам
- **Мониторинг**: Контроль процессов передачи данных

#### 3. Внешние системы
- **Внутренний кол-центр**: Прямой доступ через API
- **Партнерский кол-центр**: Получение данных через файлы
