# Требования FURPS+ для цифровой трансформации банка "Стандарт"

## Функциональные требования
| ID | Требование | Комментарий |
|----|------------|-------------|
| F1 | Клиент может подать заявку на депозит через сайт (ФИО + телефон) | Данные передаются в кол-центр для обратного звонка |
| F2 | Клиент может подать заявку через интернет-банк (выбор счета, суммы, SMS-подтверждение) | Требуется интеграция с АБС и СМС-шлюзом |
| F3 | Автоматический расчет ставок для клиентов интернет-банка | В MVP возможен ручной расчет бэк-офисом |
| F4 | SMS-подтверждение операций | Использование существующего СМС-шлюза |
| F5 | Передача заявок из кол-центра в АБС | Существующий функционал требует доработки |
| F6 | Генерация файлов со ставками для партнерского кол-центра | API не поддерживается партнером |

## Требования к удобству использования
| ID | Требование | Комментарий |
|----|------------|-------------|
| U1 | Интерфейс соответствует корпоративному стилю | Использование существующей дизайн-системы |
| U2 | Минимальное количество шагов для подачи заявки | Оптимизация UX для снижения отказов |
| U3 | Адаптивный дизайн для мобильных устройств | Большинство клиентов используют смартфоны |
| U4 | Подсказки и валидация полей форм | Предотвращение ошибок ввода |

## Требования к надежности
| ID | Требование | Комментарий |
|----|------------|-------------|
| R1 | Доступность интернет-банка 99.9% | Балансировка нагрузки между ЦОД |
| R2 | Резервный ЦОД для отказоустойчивости | Требуется настройка переключения |
| R3 | Защита от потери данных при сбоях | Регулярное резервное копирование |
| R4 | Обработка ошибок при интеграциях | Логирование и уведомления |

## Требования к производительности
| ID | Требование | Комментарий |
|----|------------|-------------|
| P1 | Время отклика интерфейса < 1 сек | Оптимизация загрузки справочников |
| P2 | Обработка до 1000 заявок в час | Учет маркетинговой кампании |
| P3 | Горизонтальное масштабирование интернет-банка | АБС масштабируется только вертикально |

## Требования к сопровождаемости
| ID | Требование | Комментарий |
|----|------------|-------------|
| S1 | Совместимость с MS SQL и Oracle | Минимизация новых технологий |
| S2 | Использование Kafka для асинхронной обработки | Требует обновления интернет-банка |
| S3 | Документация API для будущих интеграций | Упрощение поддержки |

## Дополнительные требования (+)
| Категория | ID | Требование | Комментарий |
|-----------|----|------------|-------------|
| Безопасность | SEC1 | Шифрование данных (HTTPS/TLS) | Обязательно для персональных данных |
| Безопасность | SEC2 | Разграничение доступа (депозиты/кредиты) | Требование ЦБ РФ |
| Совместимость | COMP1 | Поддержка SFTP для передачи файлов | Ограничение партнерского кол-центра |
| Аудит | AUD1 | Логирование изменений ставок и заявок | Для расследования спорных ситуаций |

## Ключевые ограничения
1. Нельзя перегружать АБС
2. Kafka пока несовместима с интернет-банком
3. Использовать существующие технологии
4. Партнерский кол-центр принимает только файлы
